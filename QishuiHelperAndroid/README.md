# 汽水助手 Android 版

这是一个面向 Android 的手动辅助工具，不会自动点击广告、模拟观看广告或自动领取广告奖励。

## 当前功能
- 桌面图标与一键打开汽水音乐（包名暂按 `com.luna.music` 配置，需在实际手机验证）。
- 引导开启 Android 无障碍服务。
- 仅监听汽水音乐前台页面的可访问文字，识别“广告已结束 / 广告播放完成 / 领取奖励 / 奖励已到账 / 领取成功”等状态提示。
- 识别到相关文字时发送系统通知，提醒用户自行确认并手动操作。
- 不执行点击、滑动、跳过、领取等动作。

## 手机端启用
1. 安装 APK 后打开“汽水助手”。
2. 点击“开启页面状态识别”，在系统无障碍设置中找到“汽水助手”并手动开启。
3. 允许汽水助手发送通知。
4. 返回应用，点击“检查识别服务状态”。
5. 点击“打开汽水音乐”开始使用。

通知是否出现取决于汽水音乐页面是否向 Android 无障碍树暴露相应文字。本项目不包含屏幕录制 OCR，也不保证能识别所有自绘页面。

## 构建
项目使用 Android Gradle Plugin 8.7.3、Kotlin Android 插件 2.0.21、JDK 17 和 Android SDK 35。GitHub Actions 构建完成后会上传 `app-debug.apk` 工件。

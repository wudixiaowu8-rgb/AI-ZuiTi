# AI 全球情报日报 · vivo 安卓实验版
2026-11-08

- 每天北京时间 08:00 调度 RSS 新闻摘要，网络抓取之后生成日报。
- 本工程与主分支原 AI-ZuiTi 嘴替 Android 项目隔离。
- 支持用 Android 分享面板手动转发给微信。
- 试验性个人微信双号发送仅在用户主动勾选风险开关、手机解锁、分身微信在桌面、主微信好友名称精确匹配时才尝试，不保证成功。
- 两个独立微信账号为必需：分身号发送，主号接收；只用一个微信号不能收到真正的好友私聊。
- 微信个人账户没有可用的官方好友自动发送通用接口，第三方 UI 自动化可能违反微信个人账号规范，存在限制风险。**默认关闭**，也不绕过锁屏或读取他人的聊天记录。
- RSS 当前只处理 IT之家、TechCrunch AI、The Verge AI，最近48小时标题和原文链接，最多12条。**不是 ChatGPT 已有每日任务的全文**，英文标题暂不保证翻译。
- 部分 vivo 版本的双开图标文案/微信控件可能与代码不一致，需要真机确认。若手机锁屏或 UI 不匹配，自动发送失败，应用仍保存日报并发通知。
- Android 14+ 精确定时权限需要本人授权；vivo 省电限制可能影响准点触发。
- GitHub Actions 生成 Debug APK，安装前确认项目来源；原有主分支不受影响。

构建：JDK17 + Android SDK35 + Gradle8.10.2，进入此目录运行 `gradle :app:assembleDebug`。
